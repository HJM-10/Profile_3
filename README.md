# Profile_3

## Orbital portfolio

A violet portfolio with a workstation opening, Overview, a vertical project timeline, selectable projects, and a pointer-responsive globe. The contact form validates and previews enquiries in the browser. It does not send messages.

One Projects section presents 24 visual covers. Its four chapters use different scroll-linked effects: a vertical fold, a shutter reveal, a 3D turn, and an iris reveal. Chapter buttons jump to a set of projects, and the picker reaches individual covers. Select a cover to read its details. Reduced-motion users get a visual grid.

Project covers include original frontend captures with sample data where applicable, project imagery, and labeled research concept artwork.

## Run locally

Use Node.js 20.9 or later.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:3113.

For a production preview, run `npm run build` followed by `npm run start`.
